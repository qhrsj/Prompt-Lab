# PROMPT / LAB · 提示词工程学习工作台

> 从 1770 条真实提示词里提炼出结构、手法与模式，做成一套可以每天练 30 分钟的离线学习应用。

一个单文件网页：双击就能用，不联网、不装依赖、不上传任何数据。12 节课、18 个可复用模式、12 条案例拆解、24 道测验题，以及一条从一句话到一集分镜的漫剧流水线。

**[⬇ 直接下载单文件版（不用 clone）](https://github.com/qhrsj/Prompt-Lab/releases/latest)**

![桌面端首页](docs/preview.jpg)

## 这是什么

不是提示词大全，也不是「100 个神级 Prompt」清单。它解决三个具体问题：

1. **说不清** —— 把「帮我写点东西」变成可验收的任务：给谁看、要什么、多长、什么算好。
2. **控不住** —— 用约束、格式、样例、自检，把输出从「平均值」里拽出来。
3. **推不动** —— 用一次一问的追问、分阶段闸门、评审官与单点迭代，把一次赌博变成多轮协作。

内容全部基于 `炉子广场-文本提示词.xlsx`（1770 条、30 字段）的逐条拆解，不是凭空写的教程。完整分析见 [`提示词结构分析.md`](提示词结构分析.md)。

### 随手记

顶栏的「随手记」是一个跨页面的全局草稿：切到别的课程不会收起，输入自动保存；可以存成多条记录，点一下追加回草稿。多标签页之间也会自动同步，只写进本机浏览器。

![随手记](docs/scratch.jpg)

细节：

- **7 套主题**：青序流光、冰川星河、暮光琥珀、曜石星云、翡翠极光、极光幻紫、深海电光
- **进度本地保存**：课程完成、错题、笔记、主题偏好都在 `localStorage`，不上传
- **全局搜索**：课程 / 模式 / 案例统一检索（`⌘K` / `Ctrl+K`）
- **随手记**：顶栏全局草稿，切换页面不收起，输入自动保存到本地；可存为多条记录、一键追加回草稿，多标签页自动同步
- **移动端适配**：抽屉导航、44px 触控区、320–1440px 无横向溢出
- **零外部请求**：没有 CDN、没有字体、没有统计脚本

## 数据与方法

对 1770 条提示词的统计（口径见分析报告）：

| 指标 | 数值 |
|---|---|
| 长度中位数 | 476 字（均值 1402，p90 3123） |
| 写了约束 / 禁止项 | 63% |
| 有编号步骤 | 46% |
| 设定了角色 | 38% |
| 带自检 / 验收 | 27% |
| 锁定输出格式 | 25% |
| 带示例 | 25% |
| **会主动反问** | **9%** |

三个结论：

1. **长不等于好**：收藏最高的一条只有 99 字。
2. **真正的差距在「反问」**：只有 9% 会先问，而这恰恰是高分段落的共同点。
3. **69% 没有指定工具**：可迁移的是结构，不是某个模型的咒语。

## 实现说明

- 原生 HTML + CSS + JavaScript，无框架、无构建步骤
- 单文件约 39 万字符，首屏插画压缩为 1100×733 WebP（111 KB）
- 诊断器是**关键词启发式**打分（身份/任务/上下文/约束/流程/格式/示例/自检/澄清协作九维），不是模型判断
- 所有数据以 JS 常量内联，视图按需渲染，切换不刷新

## 已知限制

- 诊断器只能识别「结构信号」，不能判断内容质量；分数高不等于写得好。
- 结构出现率基于关键词识别，属于**下界估计**。
- 案例库中的提示词版权归原作者，仓库仅作学习研究与评述用途，已标注来源；如有侵权请联系删除。
- 收藏数是导出时的快照，不代表长期价值。
